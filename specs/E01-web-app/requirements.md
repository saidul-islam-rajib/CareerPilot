# E01 User web app – requirements

Same requirement IDs and user stories as `specs/E01-mobile-app/requirements.md` (the web app offers every user feature, requirements §53.7), plus:

- The web app shall be responsive from 320 px phones to large desktops: bottom tab bar under 1024 px, sidebar navigation from 1024 px, two-column detail layouts on wide screens (requirements §14).
- Footers and the About page shall credit Team Sober with a link from configuration (requirements §14, acceptance criterion 80).
