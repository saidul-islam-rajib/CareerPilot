# E01 Backend API – requirements

Implements the user API (`/v1`) and admin API (`/admin/v1`) contracts used by the mobile, web, and admin apps (`packages/api-client`), so every front end can switch from demo data to the real backend by configuration (`api.mode: http`).

Requirement IDs: §13 (consent, sign-in data), §20.2, §37, §41, §46.2, §47, §48, §49, §50, §53.
