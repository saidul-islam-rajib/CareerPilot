# docs/runbooks

Operations and incident runbooks.
- [mobile-release.md](mobile-release.md): install the mobile app on Android and iPhone (test files, home screen, TestFlight, Play Store).
- [deploy-oracle.md](deploy-oracle.md): put everything on an Oracle Cloud Always Free ARM server, step by step.
- [deploy-aws.md](deploy-aws.md): the same on AWS (Lightsail or EC2).
- [deploy-common.md](deploy-common.md): DNS, `.env`, first deploy, first admin, Google callback, phone apps, backups, and updates (both clouds).
